# 不上服务器的文件说明

部署到服务器时，**只应上传构建产物**（例如 `npm run build` 生成的 `dist/`），或容器镜像。下列内容仅用于本机开发 / 课程提交，不要放到生产服务器。

## 本地专用（禁止上服务器）

| 路径 | 原因 |
| --- | --- |
| `.env` / `.env.local` | 含本机地址、密钥；用 `.env.example` 作模板即可 |
| `node_modules/` | 体积大，服务器或 CI 内重新 `npm ci` |
| `src/`、`vite.config.ts`、`tsconfig*.json` | 源码；服务器跑的是编译后的静态文件 |
| `preview/` | 零依赖本地演示，非生产包 |
| `docs/` | 说明文档 |
| `.vscode/`、`.idea/` | 编辑器配置 |
| `*.log`、`coverage/` | 调试与测试产物 |
| `package-lock.json` 可选策略 | 若用 Docker 多阶段构建，锁文件可进构建上下文，但不必单独拷到 Nginx 目录 |

## 可以上服务器的内容

- `dist/` 内全部静态文件（或 Nginx/OSS 托管）
- 生产环境变量由服务器/编排注入，**不要**把 `.env.local` 拷上去

## 本机快速准备

```bash
copy .env.local.example .env.local
# 编辑 .env.local 后：
npm install
npm run dev
```

无服务器预览：打开 `preview/index.html` 或 `python -m http.server` 于 `preview/`。
